- **On macOS the Control Center is now a native SwiftUI app instead of an embedded Electron window.** `Codex Router.app` embeds `Control Center.app` built from `apps/macos/ControlCenter`, with the same bundle identifier, executable name, `--query-lifecycle`/`--quit-for-update`/`--tray-only` contract, and tray navigation requests the Electron window had, so the tray, `bin/model-router-tray`, and existing rollback bundles work unchanged. Every page is ported, including provider setup for opencode Go/Zen and opencode free and the opencode client row on Harness. Router operations run through `apps/control-center/electron/native-bridge.mjs`, a headless host for the same `ipc.mjs` handlers the Electron window uses, so validation, the mutation queue, the version-skew gate, and credential-over-stdin handling stay in one implementation. The window needs Node.js 22.19 or newer on the machine, which the router already requires. Windows and Linux keep the Electron Control Center.
